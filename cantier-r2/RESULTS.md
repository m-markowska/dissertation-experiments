# Chapter 7 results

The four included Turkish configurations reproduce the learned tiers reported
in dissertation Table 7.3. CanTIERr-2 starts with every observed input bundle
except the right boundary and removes a bundle only when the double-witness
condition supports its exclusion.

| Target | Ordered feature set | Unique pairs | Learned tier bundles | Bundles removed from the tier |
| --- | --- | ---: | --- | --- |
| back | back, tap | 64 | `+0`, `--`, `-0`, `00` | `0-` |
| front | front, tap | 64 | `+-`, `+0`, `-0`, `00` | `0-` |
| low | low, back, tap | 160 | `++0`, `-+0`, `---`, `--0`, `-00`, `000` | `-0-`, `00-` |
| round | round, back, tap, high | 178 | `++0+`, `++0-`, `+-0+`, `-+0+`, `-+0-`, `---+`, `--0+`, `--0-`, `-00-`, `000+` | `-0-+`, `-0-0` |

For back and front, `0-` represents the consonantal bundle and is the sole
off-tier class. The retained bundles distinguish back vowels, front vowels,
the approximant `j`, and underspecified vowels. For low and round, the larger
feature sets induce finer partitions; the learner removes the consonantal
classes supported by the sample and conservatively retains the remaining
classes.

Machine-readable results are available in two forms:

- `results/turkish_tiers.json` contains the ordered feature sets, projected
  sample sizes, complete observed alphabets, and learned tiers;
- `results/table-7.3-learned-tiers.tsv` records every observed bundle, its
  segmental interpretation, and whether it is retained on the learned tier.

Regenerate and compare the reference JSON with:

```bash
python experiments/run_tier_learning.py \
  --config data/turkish/chapter7_experiments.json \
  --output /tmp/turkish_tiers.json
cmp /tmp/turkish_tiers.json results/turkish_tiers.json
```

The reference results were checked against the preserved dissertation
pipeline and the feature-bundle interpretations in Table 7.3.

## CanTIERr-2 to PRD-SEAL pipeline

The combined experiment passes the learned tier to a canonical deterministic
2-ITSL transducer and uses PRD-SEAL to learn its transition outputs. Every
projected Turkish pair is reproduced exactly.

| Target | Correct / total | Canonical transitions | Nonidentity mappings |
| --- | ---: | ---: | ---: |
| back | 64 / 64 | 31 | 3 |
| front | 64 / 64 | 31 | 3 |
| low | 160 / 160 | 64 | 4 |
| round | 178 / 178 | 144 | 8 |

The learned nonidentity mappings resolve the underspecified target bundle
(`00`, `000`, or `000+`) from its preceding tier context. All remaining
transitions retain their identity-output baseline. The saved JSON reports the
source state, input bundle, target state, identity output, and learned output
for every changed transition. Placeholder names such as `O12` are
deterministic identifiers generated by this implementation; the semantic
transition fields, rather than the identifier number, correspond to the
transducer described in the dissertation.

Machine-readable results are stored in
`results/turkish_seal_pipeline.json`. Regenerate and compare them from the
root of the `dissertation-experiments` repository:

```bash
python -m pip install -e equational-learner -e cantier-r2
python cantier-r2/experiments/run_tier_seal_pipeline.py \
  --config cantier-r2/data/turkish/chapter7_experiments.json \
  --output /tmp/turkish_seal_pipeline.json
cmp /tmp/turkish_seal_pipeline.json \
  cantier-r2/results/turkish_seal_pipeline.json
```

# Results

`runs/` is the default destination for newly captured experiment runs. Each
run contains `metadata.json` and `terminal.log`.

Historical minimal-sample logs were not retained. See `../RESULTS.md` for the
status of those reported values and the policy for new runs.

`reference/` contains the final dissertation Appendix B values as
machine-readable TSV files. See `reference/README.md` for their scope and
column conventions.
